## 👑 Owner Commands (Sovereign Authority)
**Channel ID:** Any (Owner only)

### Owner Commands
- `!owner skip <hours>` - Skip time on idle activities (no limit)
- `!owner start forge <blueprint_id>` - Force start forge project
- `!owner tick` - Manually trigger weekly sovereignty heartbeat
- `!owner debug` - View debug info (active tasks, forge projects)
- `!owner setup` - Initialize all channels and folders
- `!owner reload <cog_name>` - Hot reload a cog without restarting bot

**Examples:**
```
!owner skip 24          # Skip 24 hours on all idle activities in channel
!owner reload slayer    # Reload the slayer cog
!owner debug           # See all active tasks
```

## 💡 Tips

### Idle Activity Strategy
All idle activities (slayer, hunting, mining, fishing, woodcutting) work similarly:
1. Use `!<skill> list` to browse options
2. Use `!<skill> <action> <id>` to start
3. Wait for time to pass (or use `!owner skip <hours>` if you're the owner)
4. Use `!<skill> claim` to collect rewards
5. Romance bonding applies during combat activities!

### Time Skip
Owner can skip time in any channel with active tasks:
- Skips slayer, hunting, mining, fishing, woodcutting, and forge projects
- Processes daily passive romance bonding
- Automatically triggers claim commands when tasks complete

### Relationship Bonding
- Combat activities (slayer, hunting) grant romance bonding with equipped NPCs
- Bonding scales logarithmically with kill count
- Time skips process daily passive bonding for relationships
